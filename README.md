## 自动创建工作流

安装插件后，全局导入按钮在空白画布或其他工作流中也会出现。选好目录并通过文件校验后，插件检查当前是否具有配套可视化节点和官方生成链路；没有则自动创建内置模板，再导入素材建页。

## 自动建页与保存

全局“导入提示词与素材”或节点内“导入目录并建页”，都可选择一个章节文件夹，例如 `01/1_26`。插件查找其中的 `1_26_01`、`1_26_02`、`1_26_03` 等上传子文件夹，每份自动建立一个同名页面。每页仍保留自己的多个素材组，不按素材组拆页。也可只选择最内层目录，只创建一页。

左侧显示原文件夹名，悬停显示完整导入路径。每页独立保存公共图片/音频/视频、提示词、时长、生成参数、勾选状态、服务器任务 ID 和结果路径。切页不会覆盖其他页面。

页面内容立即写入可视化节点的 `project_json`，随 ComfyUI 工作流保存。“保存工程”另外导出整个多页面工作区 JSON。导入后仍应保存 ComfyUI 工作流或导出工作区文件，不能把尚未保存的浏览器页面当作永久文件备份。

导入所有页面的上传与引用校验完成后才替换页面列表，失败保留原工作区。重复导入不追加页面，会清除旧工作区页面及其结果记录，用新目录重建。已上传的服务器素材和原成片文件不删除。

```text
1_26/                              ← 导入时选择此章节目录，可一次建立多页

│  ├─ 素材组索引.md                 ← 本页各组时长，建议保留
│  ├─ 公共参考图/                   ← 本页所有素材组共用，只建一套
│  │  ├─ @图片1.png
│  │  └─ @图片2.png
│  ├─ 素材组1/
│  │  └─ 提示词.txt                 ← 每组唯一的提示词文件
│  └─ 素材组2/
│     └─ 提示词.txt
└─ 1_26_02/                         ← 独立页面，素材编号从1重新开始
   ├─ 素材组索引.md
   ├─ 公共参考图/
   │  └─ @图片1.png
   └─ 素材组1/
      └─ 提示词.txt
```

也可以只选择`1_26_01`，仅导入这一页。**不要选择公共参考图或单个素材组作为上传入口。** 每页公共图库独立，不跨页自动共享。图片编号必须从1连续且不重复，支持PNG/JPG/JPEG/WebP。组内不再建立参考图文件夹，也不复制同一套图片。

若确实需要，可在`1_26_01`这一层额外建立`公共参考音频/@音频1.wav`或`公共参考视频/@视频1.mp4`，对应`<Audio 1>`、`<Video 1>`。参考音频默认关闭，不需要时不创建目录、不写音频引用。当前每组模型上限为9图、3音频、3视频，公共库可保存更多。

### 每页时长索引

`1_26_01/素材组索引.md`示例：

```markdown
# 1_26_01 素材组索引

|素材组|请求秒数|提示词|
|---|---|---|
|素材组1|4|素材组1/提示词.txt|
|素材组2|6|素材组2/提示词.txt|
```

素材组从1连续编号。时长需在0.2—20.7秒范围内；未提供本页索引时尝试从提示词动作时间区间推算，无法推算则停止导入。章节汇总表不能替代本页索引。修改时长时同步修改索引和提示词时间线。

### 提示词文件格式

每个`提示词.txt`用UTF-8保存，包含以下三个字段，各一次：

```text
integrated_multimodal_description: [Shot 1] 本镜人物、场景、构图、机位、光照及角色声线。参考素材模式按需明确<Picture 1>对应身份或场景用途。
0.0～4.0秒：人物起态、刺激、动作过程和末态。有原对白才写角色（S编号）说道：<d>[Chinese]实际原对白</d>。
overall_soundscape: 环境、接触动作和呼吸等非语言声音，不重复对白。
non_diegetic_music: N/A
```

以上是填写说明，不是可直接生成的完整故事。不要把“本镜人物”“实际原对白”等说明当成成稿。台词只放在`<d>`内；无对白时删去对白示例，不虚构音频引用。自动生图模式不用手写旧Picture编号，人物映射在提交时生成。

可以用插件“创建标准目录”生成这些目录和占位文件，随后填入真实内容。自动建目录不会自动完成剧情和分镜。

## 官方采样链路

UNET / CLIP / VAE → LoRA → 官方 ModelSamplingMiniMaxH3 → MiniMaxH3ReferenceToVideo → BasicGuider / BasicScheduler / SamplerCustomAdvanced → VAEDecode 和 VAEDecodeAudio → CreateVideo → SaveVideo。

可视化插件只编辑工程、编译标准 API 请求并依次提交；不自建采样器、不注入段间音频、不使用参考音频补成片原声。实际请求经过依赖裁剪，不包含可视化元数据节点，也不包含旧导演台节点。

初始设置保留原项目第一阶段的模型、CLIP、视频/音频 VAE、Turbo 8 步 LoRA、种子666、res_multistep/simple、864×480及12/3偏移。未继续接入旧导演台的二阶段细化、面部细化、自定义 attention patch；这些不是当前首版功能。Turbo 可在官方图中手动旁路，并同步调整步数进行对照。面板参数为实际提交值；直接修改图内对应采样器/宽高字段后，也应同步面板设置。

固定官方 H3 的24fps，时长向上对齐17k+5帧。界面显示请求秒数和实际帧数/秒数；成片时长可能略长。当前按素材组保存独立视频，不自动拼接成整页长片。

“导出本组官方工作流”把当前选择的图片、音频、视频加载节点、提示词及参数写成可独立运行的纯官方图；不含可视化插件节点，便于给作者排查。

## 批量与音频

ComfyUI原生运行按钮会生成当前选中的页面/素材组，同样经过官方请求编译与音轨来源检查。需要批量时，在当前页点击“按顺序生成勾选组”，每组完成后才提交下一组，失败即停。停止按钮只停止后续提交，不打断服务器其他任务。生成期间保持该浏览器页面打开；关闭后不会继续追加后续组，已提交任务仍在服务器运行。

任务 ID 和状态保存在该页。重新打开后用“查询已提交任务”恢复状态，不会自动重复提交。结果预览使用服务器输出路径，换服务器后素材和结果文件不会随 JSON 自动迁移。

参考音频默认关闭。关闭时请求中不会残留旧音频连线；启用后只把明确引用的样本送入官方参考条件。最终 CreateVideo 音轨必须来自 VAEDecodeAudio，不允许从 LoadAudio 直接接入。模型仍可能出现多余台词或音色变化，本插件不宣称修复模型本身的音频生成问题。

## FFmpeg磁盘合并

勾选“批量完成后自动合并”后，当前页勾选组全部完成再按列表顺序合并；默认关闭。也可点击“合并勾选组”，无需重新生成。至少两组，每组需要一个已完成视频。原始分段保留，合并结果写入output/H3_Merged并可预览。失败不删除已生成视频。

仅调用插件ffmpeg目录中的可执行文件：Windows使用ffmpeg.exe，Linux x86_64使用ffmpeg（部署后chmod +x）。其他架构需替换为对应二进制。使用FFmpeg concat及-c copy，合并不进行GPU解码和重新压缩；检测到音视频参数不一致时停止。单段采样/VAE解码仍需显存。自动合并只作用于面板批量生成；原生Run和单组生成不自动合并。

FFmpeg二进制来自PyPI imageio-ffmpeg发行包，来源和wheel校验值见ffmpeg目录source文件，许可证随附。


## 生成前模型检查

“检查全部模型”按当前模式汇总官方图实际配置的主模型、CLIP文本编码器、视频和音频VAE、LoRA。自动生图模式同时检查Z-Image三个模型。所有缺失文件和缺少节点一次显示，文件前带models存放目录。模型列表无法读取时明确提示无法确认并阻止提交，不把未知当作已安装。每次批量或原生Run提交前重新检查；“只生成/更新人物图”仅检查生图链路。检查不会自动下载权重。


## 云端直接下载模型

检查模型后，缺失清单提供单项“下载”和“下载全部缺失模型（云端）”。下载在云端后台依次进行，显示排队、下载字节/进度、校验和失败原因。完成后刷新模型清单；失败可重试，重试从头下载。浏览器关闭后已提交下载继续，重新点检查可查看状态；ComfyUI重启不会自动续传。

下载仅支持model-catalog.json收录的准确文件，未收录项提示手动安装，不猜测地址。先从Hugging Face获取精确版本、文件大小与SHA256，再下载固定版本并校验；校验通过才安装，不覆盖已有同名文件。模型目录使用ComfyUI配置的对应类别首个目录。需足够云端磁盘空间及外网访问；受限仓库可由管理员在服务环境配置HF_TOKEN，网页不收集或显示令牌。

默认H3混合主模型来自steveo23社区仓库，其他当前默认模型来自Comfy-Org；每项显示来源。未在本机下载大型模型权重，云端网络和权限仍需实际验证。


## 全局入口位置修复 v0.3.2

全局入口现在固定在右上角，名称“H3 导入提示词与素材”，带v0.3.2标识；模式和备份在“导入模式与备份”中展开。入口由独立global-entry.js加载，工作室其他模块失败时入口仍显示错误信息。安装时务必完整替换云端同名插件目录，重启ComfyUI并强制刷新；本地源码不会自动部署。


## 一键安装入口

右上角“一键安装所需模型”无需先导入素材或打开工作流：自动准备配套工作流、检查当前模式的模型并提交全部已收录缺失项。节点顶部也有同名按钮。进度在工作室面板显示。重复点击不会重复排队同一个下载任务，不覆盖已有文件。节点代码缺失会另外提示更新ComfyUI，不会当模型文件下载。网络、授权和磁盘不足仍会报具体错误。


下载速度按云端最近5秒收到的数据计算，界面每秒刷新，同时显示预计剩余时间。停传5秒后速度降为0；连接、排队、校验和完成阶段分别显示状态，不保留过时速度。预计时间仅根据当前模型剩余字节估算，不含后续排队模型。


## 断点续传更新

传输提前结束和可恢复网络错误最多自动尝试4次，失败保留.h3download.part及校验标记，再次点击重试或重启后手动发起可续传。只续传相同SHA256和大小的文件；服务端忽略Range时重新下载，防止重复拼接。完整文件SHA256错误会清除损坏临时文件。传输提前结束与完整文件校验错误分别显示。


## 大面板和生成预览 v0.3.3

默认节点1600×1100，顶部“展开大面板”可脱离画布缩放占用98%窗口，Esc收起。右侧独立显示当前任务的采样帧/人物图/完整视频；每段完成和合并完成自动显示，原生Run也自动查询结果。采样帧来自ComfyUI的b_preview事件，仅接收属于本工作区当前执行任务的预览，云端需启用兼容的采样预览。采样帧不是可播放的完整视频，不含完整音轨；视频落盘后可播放声音。不发送预览帧时会显示等待状态并在完成后显示结果。下载列表独立滚动，不再挤占全部编辑区域。


下载显示0 B/s且百分比不动代表最近5秒没有收到新数据，界面会补充“已N秒未收到数据”。读取改用read1按可用数据更新，避免等待填满缓冲才更新进度；后台未返回速度字段会明确提示更新云端后台，不再伪装成0。单下载流顺序排队，主模型未完成前编码器显示排队是正常行为。


## Clash下载代理

下载区可填写明确的HTTP代理，如http://127.0.0.1:7890（仅示例，按Clash实际HTTP/Mixed端口填写）。该地址是ComfyUI后台所在云电脑的地址，不是访问网页的另一台电脑。保存后持久化到插件download-proxy.json，后续元数据和文件请求都走此HTTP代理；已有连接需等待重连，失败后点重试。留空恢复Python系统/环境代理自动识别，界面显示识别到的代理配置，不能据此证明Clash规则实际选中了哪个出口。不支持SOCKS及带凭据URL。


## 自动检测Clash

未配置手动代理时，开始下载前自动检查系统/环境HTTP代理，再检查本机127.0.0.1的7890、7897、7892、10809、8080端口；端口开放后还验证代理能访问Hugging Face，成功才采用。结果缓存5分钟，界面显示检测结果和采用的地址。“重新自动检测代理”可清除手动覆盖并重新检测；不修改Clash自身设置。不扫描局域网，不自动访问远程代理。非标准端口仍可手动填写。已建立的下载连接需等重连后使用新代理。

## 创建标准目录与提示词文件

顶部“创建标准目录”或右上角“导入模式与备份→创建标准目录”可设置章节名、上传子目录数量、每份素材组数及秒数。直接选择本机/云电脑的目录写入（需浏览器支持File System Access），不支持时下载ZIP解压。已有同名章节会另建_新建N，避免覆盖。每份上传目录生成素材组索引.md及每组唯一提示词.txt，正文三字段且不虚构音频引用。参考模式只在每份上传目录建一套公共参考图，自动生图模式不建图库文件夹。生成的是明确标注的占位模板，仍需填写真实镜头、人物、台词与素材后导入；不会自动编写故事。


## 提示词资源引用

分组提示词及公共提示词输入@显示当前页图片/音频/视频，可继续输入类型、编号或文件名筛选；方向键选择、Enter/Tab插入、Esc关闭，也可鼠标点击。插入@图片N、@音频N、@视频N，提交时仍由官方请求编译器转换。已存在资源分类型着色，缺失编号用橙色波浪线；已有<Picture N>/<Audio N>/<Video N>也高亮。颜色仅用于编辑显示，不改变保存的提示词文字和角色编号。
