# 两份独立工作流

- 角色声音设计与试听.json：只设计声音、播放、保存WAV，不生成视频。
- H3固定声线_先配音后画面.json：正式视频工程，使用固定角色样本直接生成实际对白，再锁对白生成画面；没有试听门或逐句确认。

## 云端先安装依赖

使用运行ComfyUI的同一个Python。在 /root/ComfyUI 的终端执行：

```bash
cd /root/ComfyUI/custom_nodes
git clone https://github.com/shinrali/ComfyUI-Qwen3-TTS.git
python ComfyUI-Qwen3-TTS/install.py
git clone https://github.com/badgids/ComfyUI-H3-ExactAudioLock.git
python -m pip install -r ComfyUI-H3-ExactAudioLock/requirements.txt
```

已有仓库不要重复clone；在对应目录git pull后按各包说明升级。Qwen安装器安装自己的独立运行环境及模型，不要把qwen-tts的Transformers版本直接装进ComfyUI主环境。ExactAudioLock使用ComfyUI本身的Torch/TorchAudio，不单独替换CUDA包。安装完成后重启ComfyUI、浏览器强制刷新。

模型是完整仓库目录，不是单个safetensors：

- Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign → ComfyUI/models/qwen-voice/Qwen3-TTS-12Hz-1.7B-VoiceDesign/
- Qwen/Qwen3-TTS-12Hz-1.7B-Base → ComfyUI/models/qwen-voice/Qwen3-TTS-12Hz-1.7B-Base/

由上述Qwen安装器准备完整配置、权重和所需资源，已有该包支持的HF缓存可复用。生成阶段不偷偷下载缺失模型；缺失时停止。独立运行环境位于该节点包的.venv，保留节点包目录时也需保留此目录。

## 先在额外工作流选声音

1.导入角色声音设计与试听.json。包含知夏甜柔青年女声和亦辰青年男声两条独立支路。
2.运行后通过原生PreviewAudio播放，H3SaveVoice保存WAV到output/H3_Voices，保存节点返回的音频也可下载。
3.不满意修改声线描述或seed重新生成。试听满意后下载选定WAV，之后各段复用它，不再每段重新设计声音。

## 正式工作流直接运行

1.导入H3固定声线_先配音后画面.json，再导入完整项目根目录。
2.工作室→人物设定→固定声线配音，将下载的WAV上传到对应姓名/S编号。系统自动判断：已上传样本的角色使用Qwen配音并锁定，未上传的角色由H3配音；无需开启按钮。
3.用现有生成按钮直接运行。音色样本先给Qwen3-TTS Base克隆各句实际台词，不给H3的ref_audio。旧“启用参考音频”保持关闭。
4.提示词每句对白须有起止秒数、角色姓名/S编号和<d>[Japanese]原台词</d>。当前电话亭外6句可自动读取，14/15秒不变。
5.自然配音超过时间窗就停止，先调整提示词时间或选择更合适声音；不会截断、自动变速或静默放弃锁定。

Qwen进程结束并释放模型后才进入H3。每段独立提交；一采和二采前都重新设置对白保护与AddGuide，防止二采清除旧掩码。解码后用Dialogue Audio Finalize恢复原始对白区间，其他时段环境声仍由H3生成。最终MP4可能重新压缩音频，并非文件字节完全一致。人物口型和说话归属仍需实片验收。

当前配音锁定不支持SelfLift或历史采样缓存；不要在外部重复加一套锁定。无对白段不创建配音节点，继续正常生成环境声音。试听和正式生成互不等待人工审核。新配置随工程保存，导入替换页面时沿用当前角色声音配置，服务器迁移后须重新上传声音样本。

## 验证边界

本地已进行JSON结构、原台词与说话人/时间窗编译、二采重新加锁及最终音轨选择的模拟验证。浏览器验证上传与保存设置，不代表已经在你的云端生成过声音或验证过口型。需先用短段在云端验收。

## 插件内下载
模型与下载页提供“下载正式配音模型（Base）”和“下载声音设计模型（试听）”。各自下载11份必需文件（含speech_tokenizer），保留目录结构；可使用现有代理、下载源选择、断点续传与速度显示。正式配音绑定样本后，检查/安装所需模型也会列出缺失的Base文件。下载权重不代替Qwen独立Python环境和ExactAudioLock节点安装。
