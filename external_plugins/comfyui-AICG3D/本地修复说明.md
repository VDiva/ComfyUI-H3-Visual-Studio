# 重复安装导致最终合成与二采节点缺失

本目录复制自用户下载的 AICG3D v1.1.27，保留上游 GPL 许可及源文件。
仅新增 tools/fix_duplicate_installations.py、回归测试和本说明。
它是独立插件源码，不由外层导演台自动注册；部署时应放在 custom_nodes 直属子目录。

日志显示 comfyui-AICG3D 与 aicg3d-h3-suite 同时加载；二者使用相同的
aicg3d 等绝对模块名，Python 模块缓存可能让新安装使用旧版本模块。
修复重复安装比清理模块缓存可靠，也避免 HTTP 路由和前端扩展重复注册。

上传本目录的 tools/fix_duplicate_installations.py 到云端保留插件相同位置后：

```bash
cd /root/ComfyUI/custom_nodes/comfyui-AICG3D || exit 1
/root/miniconda3/envs/comfyui/bin/python tools/fix_duplicate_installations.py
/root/miniconda3/envs/comfyui/bin/python tools/fix_duplicate_installations.py --apply
```

脚本按 pyproject.toml 的项目名识别重复安装，将它们移到
ComfyUI/disabled_custom_nodes/时间戳目录，保留文件，不删除模型或工作流。
拒绝非 custom_nodes 直属部署位置、缺失目标模块和符号链接副本。
完成后重启 ComfyUI，浏览器强制刷新，再验证：

```bash
/root/miniconda3/envs/comfyui/bin/python tools/fix_duplicate_installations.py --check-server http://127.0.0.1:8188
```

本地仅完成文件操作的隔离回归测试，未在用户云端执行或验证 GPU 推理。
